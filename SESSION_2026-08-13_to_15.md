## 1. The headline finding: the transfer-matrix column was wrong at p ≠ 0

`ITransverse.build_Ut` builds `U(dt)` on **three sites** and repeats the middle tensor as the column
of the rotated network (`build_Ut.jl:24-27`; `make_fwtmpoblocks` asserts `length(eH)==3`). For a
nearest-neighbour model site 2 of a 3-site chain is a genuine bulk site, so this is exact. For our
NNN model it is not: that site has no site+2 to couple to, so the extracted column is missing a
memory channel — temporal site dimension **7 instead of 13** (VD2).

Evidence, all measured:

| test | legacy column | corrected column |
|---|---|---|
| tile the column, compare with the honest 6-site operator | 0.34 relative error at p = 0.05, 0.1, 0.3, 0.5 | **0.000e+00 everywhere** |
| same test at p = 0 | 0.000e+00 | 0.000e+00 (identical operators) |
| Krylov echo referee vs exact evolution, p=0.1 (T=1,2,3) | +0.0035, +0.0049, +0.0095 | +0.0016, +0.0018, +0.0055 |
| Krylov echo referee, p=0.5 | +0.032, −0.009, −0.047 | +0.0048, +0.0073, −0.023 |
| p = 0 error floor (Trotter + extrapolation) | ±0.001 | ±0.001 |

The corrected column is 2–7× closer to the exact echo at every frustrated point. Legacy's
sign-flipping errors at p=0.5 are the branch instability seen all along.

### Consequence 1 — the π-displaced tower does not exist

The corrected column shows the **ordinary Ising boundary tower** next to λ₀ at every coupling.
Converting the tower blocks' phase gaps with the extrapolated velocities:

| block | leading gaps → x |
|---|---|
| p=0.1, T=2 | 0.48, 1.47, 1.99 |
| p=0.1, T=3 | 0.49, 1.52, 2.03, 3.14 |
| p=0.5, T=2 | 0.50, 1.60, 2.22 |
| p=0.5, T=3 | 0.49, 1.55, 2.11 |

The K-projected run at p=0.5 confirms the sector assignment: odd sector leaders convert to
x = 0.497 and 1.556, even sector to x = 0 and 2.11 — i.e. {1/2, 3/2} odd and {0, 2} even, each at
its ordinary CFT phase. Sector ratios close toward one as T grows (0.9825 → 0.9942), which is the
emergent dual unitarity.

**Decision taken (user):** the thesis will not mention the displaced tower at all. Memory file
`velocity-puzzle-jul2026.md` is marked SUPERSEDED.

### Consequence 2 — the Z2 sector structure survives

K is an **exact** symmetry of the corrected column: |EK−KE|/|E| ≈ 1e-16 at p=0.1 and p=0.5, with a
one-dimensional intertwiner nullspace and a 13-entry alternating signature. The 339 "mixed"
eigenvectors in the dense census were plain-`eigen` degeneracy artefacts, not symmetry breaking.

### Consequence 3 — the corrected column is far better conditioned

At p=0.5, T=3 the corrected column returns |μ₀| = 1.8639 across three solver settings (k=4 χ=64,
k=8 χ=48, k=8 χ=40), agreeing to 4–5 digits. Legacy scattered by 18% over the same variations.
An entropy rung that legacy could not converge now converges in **55 iterations**.

## 2. The fix, as implemented

Implemented **in our own code**, not as a fork — the Manifest pins ITransverse to a commit the
collaborator's cluster environment is built on, and every production path constructs the blocks in
our `src/transverse_tools.jl`, so the package never needs touching.

- `bulk_fwtmpoblocks(tp; nsites=5)` — builds U on 5 sites, takes the true middle tensor, swaps it
  into the blocks structure (only `Wc`/`Wc_im`; `fw_tMPS` cannot run on the swapped blocks, so
  `:bulk5` seeds with a random MPS — harmless, production always randomises seeds anyway).
- `column::Symbol` keyword threaded through `build_tmpo`, `build_alcaraz_tmpo`,
  `compute_entropies`, `run_pm_diagnosed`, `ksector_signs`. `:legacy3` (default) | `:bulk5`.
- Cluster driver: `WALL_COLUMN=bulk5` env var, `_bulk` suffix on label/cache/checkpoint;
  `WALL_DT` (with NBETA derived so β₀ = 0.2 always) and `_dt<val>` suffix; `WALL_BLAS_THREADS`.
- KrylovKit added as a direct dependency (Project.toml, +1 line; ITransverse pin untouched).

**Validation battery:** `NBs/13_bulk_column.ipynb` — executed, all cells green.

### Key physics results from the local runs

**Single-vector p=0.1 (corrected column), T=2–12** — conformal plateau from T=4 to T=11:

```
T      4      5      6      7      8      9     10     11     12
c_Re  0.684  0.701  0.693  0.697  0.688  0.665  0.668  0.618  1.006
```

Legacy died at T=9 here. Finite-T fits over the clean window: c = 0.62 (T^-1/2) vs 0.67 (1/T),
rms 1.10e-1 vs 1.07e-1 — **statistically indistinguishable, so this window cannot settle the
Bou-Comas decay power**. Im plateau: 0.62 vs 0.64.

**Single-vector p=0.5 (corrected column), T=2–10** — the entropy route works at p=0.5 for the
first time: c_Re = 0.58, 0.52, 0.66 at T = 3, 4, 5; breaks from T=6 as the rigidity reaches
1e-6–1e-7. |μ₀| stays on the dual-unitary circle (1.849–1.873) through T=10, five rungs past the
entropy wall. (Ignore the Eq.(3) and BC summary fits printed by that script: the first used
wrapped phases without branch unwrapping, the second ingested the broken T≥6 rungs.)

**Rigidity is extensive** — falls geometrically with chain length at every coupling, e.g. p=0.1:
0.044 (T=2) → 4.0e-9 (T=12), while |μ₀| stays clean. This is the sober form of "eigenvalues
outlive eigenvectors": generic non-Hermitian perturbation theory, not an exceptional point.

**Equilibrium anchors extended to p = 1.0 and 1.5** (new): c = 0.5036 and 0.5055 (N=400 chord fit),
v_∞ = 8.1265 and 10.7992. Velocity extrapolation `v(N) = v_∞ + C/N²` over N = 10–18 now covers
p = 0, 0.1, …, 0.5, 1.0, 1.5; control at p=0 gives 1.99994 against the exact 2 (error 6e-5).
